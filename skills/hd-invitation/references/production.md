# 高清生成与精确修改

## 先分配像素，后生成

不要用一张低分辨率长图当最终画布，再靠锐化补救。密集长图先确定目标画布与正文字号。图形、文字可由模型生成，标识与二维码单独使用原始素材层。

如果内置工具对整图输出固定像素量，文字越多、纵向越长，每字分到的像素越少。优先按自然版块分段：标题区、日程组、说明规则区、联系与报名区。各段比例接近时更容易得到相近的原生像素密度。

- 第一次生成单段后读取实际尺寸；据此确定其余段目标和最终画布，不能仅在提示词写“4K”。
- 分区围绕内容安排，不在一行文字中间切开。裁片可保留少量重叠背景用于对齐，但真正拼缝须位于无字空白处。
- 不要对重叠文字交叉淡化，否则原本正确的“日”可能因横线叠加看似“目”。框线和装饰也须检查接缝。
- 优先裁切或少量缩小原生生成块；不要大幅放大某段以满足总尺寸。像素数高但细节糊仍不通过。
- 逐段检查后再拼接。最终仍要检查整张，否则漏字、重复行、切字和接缝错误可能只在合成后出现。

## 分段生成提示词模板

```text
用途：中文活动邀请函的高清内容区，输入为已批准版式的第 N 段。
任务：按输入原位生成清晰细节，输出尽可能高的原生分辨率。
保持：相同比例和裁切边界、所有相对坐标、文字行数、颜色、版式、日程顺序、字号层级。
只改善：字形笔画、边缘清晰度和画面细节。
禁止：新增内容、改写、补全被裁掉的相邻版块、增加白边、把本段改成独立卡片。
精确文案：<从 copy.txt 取本段全文；注明课程分隔符不是要新增的标点>
文字要求：标准简体中文，真实可读笔画；正文勿全部加粗，所有 Part 编号与文案完全一致。
品牌/二维码：保留预定位置，由原始素材后续嵌入，不设计替代标识或假二维码。
```

无现成版式时，先根据源内容设计统一的画布布局、品牌配色、分区坐标和版式规范；这是内部工作，不要求用户批准每一步。各段使用同一视觉规范。

## logo 原始资产处理

优先透明矢量或高分辨率 PNG。只有带背景模板时，从用户明确指定的模板提取最高质量版本，去底时检查细线、负形、镂空、文字和色彩；不能用全图粗暴阈值破坏白色/浅色标识。

不得默认使用某医院、公司或旧项目 logo。多个机构标识按用户关系排列，不擅加认证章、印章、赞助商。头尾标识使用同一原始源，按场景缩放；建筑招牌需要透视变换时仍基于原始标识，而不是模型重新画。

提取不到清晰标识时，说明限制并请求源文件，或者根据用户选择省略/改用纯文字。不要承诺凭空恢复真实品牌细节。

## 二维码

二维码不能让图像模型生成或修补。原码等比缩放，保留至少四个模块静区，优先整数模块缩放；缩小采用最近邻，避免抗锯齿使边缘灰化。静区不能被圆角、装饰、文字遮挡。

先解码源二维码，再解码最终完整成品，两者须一致。只有报名链接时可用确定性二维码库生成并核对链接。不要自行打开链接提交报名，也不把私人二维码上传第三方识别网站。

## 已批准图片的局部修改

1. 记录基准文件和允许变更的矩形/掩膜。
2. 裁出目标区域，模型仅修复相应文字或画面；精确贴入 logo/二维码时直接用原资产。
3. 核对生成字形后只提取目标部分，避免同一裁片其他正确文字也被重画。
4. 贴回原位后，目标外像素差异为零。验证目标及其相邻文字、标点、行距。
5. 不覆盖基准，另存版本。若用户要求整体高清重建，则改用整体内容和版式一致性校验，不套用像素不变承诺。
