# 高清邀请函 Skill · HD Invitation

一份资料，制作清晰、好看的中文高清邀请函。适用于会议、论坛、培训及活动，不限行业、不限单位。

**[⬇️ 直接下载 Skill 压缩包](https://github.com/dandanzhangnihao/hd-invitation/raw/refs/heads/main/downloads/hd-invitation.skill.zip)** · **[查看资料清单](skills/hd-invitation/references/intake.md)** · **[查看 Skill](skills/hd-invitation/SKILL.md)**

## 怎么安装

在支持 Skills 的 Codex 中，复制下面这句话：

```text
请使用 skill-installer，从 https://github.com/dandanzhangnihao/hd-invitation/tree/main/skills/hd-invitation 安装高清邀请函 Skill。
```

也可以点击上面的下载链接，解压后将 `hd-invitation` 文件夹放入 Codex 的 skills 目录（默认 `~/.codex/skills/`，或自定义 `CODEX_HOME` 下的 `skills/`）。已有同名版本时先保留备份，不直接覆盖。安装后在下一轮对话中调用；若客户端尚未识别，可重新打开客户端。

“直接下载”只下载文件，不会自动执行程序。制作需要支持 Skills 与生图工具的运行环境；这个仓库本身不是在线生图网站。

## 一句话使用

上传活动资料、原始 logo 和报名二维码，然后发送：

```text
使用 $hd-invitation，按我提供的资料制作高清邀请函。
默认使用柔和中蓝；如有参考图，请按参考图调整配色。
```

## 需要哪些资料

| 基本资料 | 内容 |
|---|---|
| 活动名称 | 正式名称、届次或期次 |
| 时间地点 | 日期、时间、会场地址或线上形式 |
| 内容与日程 | Word/PDF 或文字；日程包含时间、课程和讲者姓名及单位 |
| 机构信息 | 主办、承办等准确名称和原始 logo |
| 报名方式 | 二维码或链接；也可注明预留空框或无需报名 |

费用、名额、学分/证书条件、联系人和电话按需提供。主持人尚未确认时不展示。附件中已有的信息不需要重复填写。

## 能做什么

- **配色可定制**：默认柔和中蓝，也可按机构品牌色、偏好或参考图调整；不强制先选配色。
- **高清输出**：输出无损 PNG。密集长图通常规划为宽 1800–2400 px、长边至少 4000 px，并核对实际字形细节；不把插值放大或修改 DPI 当成原生高清。
- **中文与内容校对**：核对日程、编号、姓名、单位、日期、费用等；OCR 与视觉复核结合。
- **原始标识与二维码**：原样嵌入提供的 logo 和二维码，验证成品扫码内容，不让模型编造。
- **局部修改**：更新讲者、单位、文字或报名信息，保护未授权修改区域，避免反复重绘整张海报。
- **通用版式**：标题、日程、说明及报名区分层清楚；多位讲者默认只标一次“讲者：”。

## 运行要求

- 具有 Skill 支持、内置图像生成/编辑能力和本地文件读写能力的 Codex 环境。
- 附带的确定性图像工具需要 Node.js 与 `sharp`；可使用环境已有依赖，操作方式见 [工具说明](skills/hd-invitation/references/tooling.md)。
- 附带的 OCR/扫码脚本使用 macOS Swift Vision。其他系统需要可用的本地 OCR/二维码解码工具；不能把未执行的检查当成通过。
- 生图耗时与可用额度取决于使用环境。最终发布前仍应核对活动事实，Skill 不承诺绝对零错字或任意放大清晰。

本仓库仅提供通用流程与辅助工具，不附带任何单位的客户资料、真实电话、报名码或品牌素材。
